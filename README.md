# 🪷 ลอยกระทง

เว็บลอยกระทงออนไลน์สำหรับคนสองคน — ผ่านเรื่องเล่าสั้น ๆ ก่อนลอยกระทง เลือกสีกลีบดอกไม้ จุดเทียนสามเล่ม หลับตาอธิษฐาน แล้วค่อยกดลอยกระทงสองใบลงสู่สายน้ำสีชมพูไปด้วยกัน

ไม่ต้องติดตั้งอะไร ไม่ต้อง build — เปิด `index.html` ได้เลย

## ✨ สิ่งที่มีในเว็บ

- **หน้าปก** พร้อมปุ่ม “เริ่มค่ำคืนของเรา” และกระทงคู่เล็ก ๆ ใต้พระจันทร์ในธีมพาสเทลชมพู
- **เรื่องเล่าก่อนลอยกระทง 3 คำถาม** — คืนนี้อยากลอยกับใคร / ถ้าอธิษฐานได้หนึ่งข้อจะขออะไร / พร้อมไปลอยกระทงหรือยัง (เลือกได้ข้อละ 3 ตัวเลือก)
- **เลือกสีกลีบดอกไม้ 4 โทน** (ชมพูหวาน / พีชอุ่น / ฟ้าพาสเทล / ลาเวนเดอร์) พร้อมพรีวิวกระทง และสีที่เลือกจะถูกใช้กับกระทงทั้งสองใบจริง
- **จุดเทียนให้ครบ 3 เล่ม** — แตะเทียนที่ตั้งอยู่บนตัวกระทงทีละเล่ม (ใช้สีกลีบที่เลือกไว้)
- **หลับตาแล้วอธิษฐาน** — ข้อความอธิษฐานเพื่อความทรงจำดี ๆ และช่องให้เขียนคำอธิษฐานของเธอเอง (**ต้องเขียนก่อนกดไปต่อ**)
- **ลอยกระทงด้วยกันนะ** — หน้าสุดท้ายของเรื่องเล่า มีปุ่ม “ลอยกระทง” ให้แตะเพื่อปล่อยจริง
- กระทงสองใบ (คนละการเรียงสีดอกไม้) พร้อม **เทียน 3 เล่มติดไฟ** เหมือนตอนจุด (ไม่มีข้อความสลักบนกระทง)
- ฉากมินิมอลโทนชมพู: พระจันทร์เต็มดวงพร้อมแสงนวล ดาวระยิบระยับ กลุ่มดาวรูปหัวใจ เมฆนวลลอยช้า ๆ แสงเหนือพาสเทล ดวงใจลอย โคมลอยไฟ หิ่งห้อยริมน้ำ กอหญ้าริมฝั่ง เงาสะท้อนบนน้ำ และดาวตกเป็นครั้งคราว
- ปุ่มลอยกระทง: กระทงลอยขึ้นจากน้ำ เทียนติดทีละใบ มีเกล็ดไฟ/ดอกไม้โปรย และระลอกน้ำกว้างใต้กระทง
- กระทงสองใบลอยเข้าหากัน แล้วมีเส้นหัวใจสีชมพูเชื่อมป้ายชื่อทั้งสอง พร้อมดอกไม้ไฟพาสเทลจาง ๆ
- ทุกครั้งที่กระทงบรรจบ จะลุ้น **อีเวนต์พิเศษสุ่ม 1 ใน 4**: ฝนหัวใจ / ดาวตกชุดใหญ่ / โคมลอยพิเศษ / ดอกไม้ไฟยักษ์ (ไม่ซ้ำกับรอบก่อนหน้า)
- การ์ดเรื่องเล่ามีลายดอกไม้ประดับที่มุม และแถบจุดบอกความคืบหน้า
- แตะที่กระทงเพื่อโปรยหัวใจ
- เพลงบรรเลงเบา ๆ จาก Web Audio (กดปุ่ม ♪ เพื่อเปิด/ปิด)
- ปุ่ม **🕯️ ลอยโคมไฟ** ใน HUD — ปล่อยโคมใหญ่กลางจอพร้อมโคมเล็กเป็นเพื่อนลอยขึ้นฟ้า (กดได้ครั้งเดียว แล้วปุ่มจะหายไป)
- หลังลอยกระทงจะมีปุ่ม **💗 ไปดูความทรงจำของเรา** — เปลี่ยนเป็น **หน้าเต็มจอ** ที่เลื่อนดูรูป 2 ใบ (แถวบน) + วิดีโอ (แถวล่าง) พร้อมหัวข้อและอิโมจิประดับ มีปุ่ม **💌 มีจดหมายถึงเธอคนเก่งของเค้าด้วยนะ : )** กดแล้วเป็นซองจดหมายให้แตะเปิด (ข้อความในจดหมายรอเติม) (กลับได้ด้วยปุ่ม ✕ หรือกด Esc)
- รูปและวิดีโอความทรงจำใช้ path แบบ relative เปิดได้เลยจาก GitHub Pages (อัปอยู่ใน repo นี้แล้ว)
- ไม่บันทึกข้อมูลลงเครื่อง — เปิดหน้าใหม่เริ่มเรื่องใหม่เสมอ

## ▶️ วิธีเปิด

**ง่ายที่สุด:** ดับเบิลคลิก `index.html`

**หรือเปิดผ่านเซิร์ฟเวอร์ในเครื่อง** ถ้าอยากทดสอบบนมือถือในวง Wi-Fi เดียวกัน — ใช้ส่วนขยาย **Live Server** ใน VS Code หรือโปรแกรม static server ใดก็ได้ แล้วเปิดโฟลเดอร์นี้

> หมายเหตุ: ฟอนต์ Itim / Prompt โหลดจาก Google Fonts ถ้าไม่มีอินเทอร์เน็ตจะใช้ฟอนต์ไทยในเครื่องแทนได้

## 🎨 ปรับแต่ง

| อยากเปลี่ยน | ไปที่ |
| --- | --- |
| โทนสีชมพู / สีพื้นหลัง | `:root` ใน `styles.css` |
| คำถาม / ตัวเลือกในแต่ละขั้น | การ์ด `.story-panel` ใน `index.html` |
| ชุดสีกลีบดอกไม้ 4 โทน | `PALETTES` ใน `app.js` และ `.swatch.*` ใน `styles.css` |
| คำอธิษฐานเริ่มต้น / ข้อความในหน้าอธิษฐาน | `state.wish` ใน `app.js` และ panel `data-step="wishnote"` ใน `index.html` |
| ชุดอีเวนต์พิเศษ / ชื่ออีเวนต์ | `SPECIAL_EVENTS` ใน `app.js` |
| จำนวนโคมเล็ก / ตำแหน่งโคมใหญ่ | `spawnSkyLanterns` ใน `app.js` และ `.sky-main` ใน `styles.css` |
| ชื่อเว็บ / ข้อความเปิด | `index.html` |

## 📁 ไฟล์

- `index.html` — โครงหน้าเว็บ + เรื่องเล่า 8 หน้า (หน้าปก + 7 ขั้นตอน: คำถาม 3 ข้อ → เลือกสี → จุดเทียน → อธิษฐาน → ลอยกระทง)
- `styles.css` — ฉากสีชมพู กระทง การ์ดเรื่องเล่า แอนิเมชัน และ responsive
- `app.js` — วาดกระทง/ดาว/ดอกไม้ เพลง โคมลอย ลำดับขั้นตอน และการลอยกระทง
- `memory-1.jpg`, `memory-2.jpg` — รูปที่บีบอัด/ย่อขนาดแล้ว (โหลดล่วงหน้า) ใช้แสดงในหน้าความทรงจำ
- `*.jpg` ต้นฉบับ, `*.MOV` — ไฟล์ต้นฉบับเก็บไว้ใน repo (ไม่ได้ใช้แสดงผล)
- `memory-video.mp4` — วิดีโอความทรงจำ (แปลงจาก `.MOV` เป็น MP4 เพื่อให้เล่นบนเบราว์เซอร์ได้)
